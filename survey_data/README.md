# Survey Data & Research Artifacts (`/survey_data`)

## Contents & Overview
This folder contains all foundational research data, previous laboratory exercises, user personas, empathy maps, and analysis documents created during the JobNest UI/UX development lifecycle.

### File Index
- Consolidated report covering all 7 UI/UX Lab Assignments.
- 6 Target User Personas spanning freshers, career switchers, and executives.
- Comparative Empathy Map (Naukri.com vs. LinkedIn vs. JobNest).
- Comparative UX analysis of Naukri, LinkedIn Jobs, and Indeed.
- Structural wireframes and low-fidelity screen layouts.
