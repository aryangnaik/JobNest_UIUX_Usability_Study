# Audio Files Directory (`/audio_files`)

## Contents & Overview
This folder contains the raw audio recording from the 1-on-1 qualitative Think-Aloud usability testing session comparing Naukri.com (Original Website) against JobNest (Modified Prototype).

### File Index
- Complete 1-on-1 usability testing session recording.

### Methodology & Testing Protocol
- Participant Profile: Batchmate / Friend unfamiliar with the JobNest prototype domain to prevent bias.
- Testing Format: 1-on-1 think-aloud protocol across 5 candidate scenarios.
- Scenarios Covered: Filter search with salary display, employer verification, Easy Apply flow, real-time application tracker, and side-by-side opportunity comparison.
