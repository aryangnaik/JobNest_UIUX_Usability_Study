# Transcripts Directory (`/transcripts`)

## Contents & Overview
This folder contains the speech-to-text transcriptions and qualitative thematic analysis generated from the Think-Aloud audio recordings.

### File Index
— Full transcript of candidate verbalizations during tasks on Naukri.com vs. JobNest.

### Key Vocalized Themes & Insights
1. Ad Clutter vs. Calm Design: Participant noted that Naukri's home screen was "overcrowded with popups and ads," whereas JobNest felt "clean, peaceful, and straightforward."
2. Salary Visibility: Participant expressed frustration on Naukri over "Salary Not Disclosed" tags, praising JobNest for showing exact compensation bands (e.g., ₹8–11 LPA) upfront.
3. Application Friction: Participant highlighted that Naukri's external redirects to Workday/Taleo caused "application fatigue," while JobNest's Easy Apply took "less than 5 seconds."
4. Application Anxiety: Participant vocalized feeling like applications went into a "black hole" on Naukri, while JobNest's visual step-tracker provided "complete peace of mind."
